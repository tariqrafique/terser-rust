# Compress board triage

Triage of the `default` board after the T4/T5/T7 merge (`cb70bc5`): compress `default` 2435/2671 (236 failing), lwc 339/339, bundles 0/3. No compressor code was changed for this. `PLAN.md` is the plan, `PORT.md` the history, `TRIAGE.md` the lwc-rollup triage. This file covers the terser test-suite inputs and the three bundles.

## What the `default` set is

`--set default` runs `minify(input, {})` on every `test/compress` input: terser's own defaults (compress on, mangle on, `toplevel` off, one pass, default `format`). The case's own options (`fixture` in the case JSON) are not used. They are the `fixture` set, a separate board (below). So for this board an option named in the test file (`unsafe_*`, `keep_fargs`, `passes`, `pure_funcs`, `ie8`, `toplevel`, `hoist_vars`, `module`, `ecma`, `beautify`, `comments`...) is not what fails. What fails is the default compressor on that input.

## Method

- The full failing list: the harness has no flag for it (each group prints 8). After a run, `harness/.board-cache/failed.tsv` holds every failing id. `./target/fast/harness board --case <id>` prints the full expected and actual output.
- Each failing input was also run with `{mangle:false}` through terser and the port. Every one of the 236 still differs, so none of them fails in the mangler only.
- `tools/trace-diff.sh <input> '{"mangle":false}' --opt` on every case gave the first divergent compressor decision. The clusters below come from that decision, not from the final output.
- The port's output was run under node for each case that has an `expect_stdout`, to find outputs that are wrong, not just different.

## Mangler bug (from another agent, confirmed) - fixed (T6, `scope: keep exported names out of every scope's mangled names`)

No compress case shows this. lwc-rollup inputs are modules, so it can matter there. Owner: T6 (scope crate).
